Conventions:
- Value = quantity x mark x explicit multiplier (no default); reporting = local x rate. Exact `Fraction` products, rounded once toward minus infinity at 1e-12 (assets down, liabilities away from zero), so value and unrealized gain are never overstated.
- Unrealized = value - remaining average cost (`postings.LOT_POLICY`). In the reporting currency it needs `cost_reporting` (cost at historical rates). `cost_reporting` is caller-trusted: it is not cross-checked against the journal or any FX history. Realized P&L is the journal's, per currency, untranslated.
- `Unavailable`, never zero: missing, non-positive, stale or future mark or FX; missing multiplier; unsupported short; unknown cost; an account with no journal rows (`account_unknown`). NAV is unavailable if any part is; the available total is labelled partial.
- Staleness: an input is fresh while age <= `max_age` (equal is fresh, one microsecond more is stale). The spec gives no boundary; this is an implementation choice.

## PR B — returns
| Path | What |
|---|---|
| `packages/domain/src/qw_domain/returns.py` (new) | `time_weighted_return`, `money_weighted_return`, `fx_attribution`. |
| `packages/domain/tests/test_returns.py` (new) | 33 tests. |

Conventions (the module docstring has the detail):
- TWR links exact sub-periods at flows; half-even at 1e-18. Missing valuation, non-positive start, negative end value (`negative_end_value`), equal or decreasing times: `Unavailable`. An end value of exactly 0 is -100%.
- MWR solves sum(CF_i y^d_i) = 0 with y the daily discount factor (integer powers only), ACT/365F annualization for horizons >= 365 days or on request.
  - Unique root when the net flows change sign once (Descartes), or when the partial sums from the start and from the end change sign once in total, with a positive last flow (Laguerre's bound; Norstrom's criterion alone only rules out a second root with r > 0, so the sums from the end are also checked).
  - Otherwise `ambiguous`, with candidate roots from a 5% grid and no single value.
  - A zero terminal value after contributions only is a total loss: -100%, `uniqueness_rule` `total_loss`.
  - `growth_domain` for 1 + p defaults to [1e-6, 1e6] and is a parameter. This range is an implementation choice, not from the spec.
  - Bisection to 1e-30 in y; hitting `MAX_ITERATIONS` warns `not_converged`. `residual` is at the unrounded solver root, not the 18-place `Ratio`.
- FX: interaction rounded half-even; local + currency + interaction = reporting.
