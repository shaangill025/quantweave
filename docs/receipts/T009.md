### Changes
- `decimals.py`:
  - **S1.** `BoundedDecimal.__reduce__` returns `(cls, (to_wire(),))` and `Money.__reduce__` returns `(Money, (amount, currency))`. `copy`, `deepcopy` and `pickle` therefore rebuild through the validating constructors. A crafted protocol-0 pickle carrying `"-0"` raises `DecimalValueError`. The eight subclasses declare `__slots__ = ()`.
  - **S2, decision:**
    - Mixed numeric operands raise `TypeError`: float, int, bool, Decimal, Fraction (`numbers.Number`), str/bytes (likely wire strings), another value class, or Money against an amount. This holds for `==`, ordering and arithmetic.
    - Unrelated non-numeric types (None, object, …) get `NotImplemented`. `==` is then False, so `x in [None]` works, while ordering and arithmetic still raise `TypeError`.
    - `Money == Money` across currencies **returns False**. Equality needs no FX rate, because amounts in different currencies are never the same value. Raising would make `set`/`dict` membership of mixed-currency Money depend on hash collisions.
    - Arithmetic and ordering across currencies still raise `CurrencyMismatchError`. Tests cover a mixed-currency set, `usd != cad`, `<`/`>=` raising, and `None` membership.
    - Residual: a set that mixes value *classes*, such as Price and MoneyAmount, can still raise on a hash collision. Mixing classes is a design error, and this is accepted.
  - `safe_repr` caps input in error messages at 64 characters (also used by `instants.py`).
  - `quantize` rejects negative, zero and non-power-of-ten quanta.
  - `Rounding` is now an `Enum` with four distinct members, so `LOT` is no longer an alias of `PROCEEDS`. Each member's `.mode` property gives the decimal rounding mode.
  - **Known gap for T012:** lot sizing only supports power-of-ten increments, so a lot of 5 or 0.25 needs a floor(q / lot) × lot step.
- `instants.py`: `ensure_aware_utc` and `format_instant` raise `InstantError` on UTC overflow (year 9999 at −05:00, year 1 at +01:00).
- `tools/check_no_float.py`:
  - **New rules:**
    - `float-attr` catches `builtins.float` and any `.float`.
    - `float-import` catches `from … import float [as x]`.
    - Quoted strings are now parsed recursively inside annotation subscripts, `type X = "…"`, and `cast(...)`/`typing.cast(...)` first arguments.
    - `division` catches `/` and `/=`.
    - Coverage: every `packages/*` directory must be in `MONEY_PATHS` (now per package) or in `NOT_MONEY` (`quant`, ADR-013), and the listed paths of an existing package must exist.
  - `ALLOWLIST` is now keyed by (file, rule); it is still empty.
  - The docstring lists the remaining limits: getattr/eval, library-returned floats (json, math, time, statistics), `int.__truediv__`, and negative `**`.
- `tests/test_guards.py`:
  - `import_module`/`__import__` calls are caught when aliased (`from importlib import import_module as load`) or passed by keyword (`name=`).
  - A non-literal target fails as an unreviewable dynamic import in every `packages/*` file, tests included.
  - `from a import b` is checked as `a.b`, so `from asyncio import subprocess` is caught.
  - Any `.py` outside `tests/`/`conftest.py`, including stray files, gets the package allowlist.
  - Domain gets a denied stdlib list: socket, socketserver, ssl, http, urllib, ftplib, smtplib, poplib, imaplib, xmlrpc, webbrowser, sqlite3, dbm, shelve, subprocess, asyncio.subprocess, multiprocessing, ctypes, pickle, marshal, runpy, importlib.util, zipimport.
- Tests added: hash/eq consistency (unit and property), Money ordering and hash, quantize on UsdBudget (COST up, including negative), Quantity (LOT), Price (half-even), a quantum finer than the scale, negative quantum, distinct `Rounding` members, repr caps, copy/pickle, and None handling.
