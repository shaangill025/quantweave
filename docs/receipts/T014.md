## Changes
- `packages/domain/src/qw_domain/csv_import.py` (new)
  - Format `canonical-csv/1`: the 11 fixture columns plus optional `fee_currency`. The version is declared on the `ImportRequest`; any other version rejects the file.
  - File checks, each rejecting the whole file (`state = rejected`): byte limit, NUL byte, strict UTF-8 (a leading BOM is removed), strict `csv` reader (`strict=True`, CRLF or LF), row, column and header-cell limits, duplicate header, mapped column missing, empty file.
  - `ColumnMapping(version_id, {source header: canonical field})`: every canonical field mapped exactly once; unknown targets and duplicates rejected. Unmapped headers are an `unknown_columns` (non-blocking) issue, and their cells are kept per row as `unknown_fields`, never interpreted.
  - `FileKind.TRANSACTIONS` or `SNAPSHOT`. A row of the other kind is quarantined (`mixed_file_kind`). Transaction rows become `postings` events; snapshot rows (`position`, `cash`) become `SourceSnapshot`s for `sources.consolidate` and never post.
  - Row outcomes: accepted (with event or line, plus a `SourceObservation`), duplicate, conflict, or quarantined with a `Reason`: column_count, field_too_long, formula_injection, invalid_reference, malformed_timestamp, malformed_decimal, scale_overflow, unknown_kind, mixed_file_kind, currency_invalid, mixed_currency, field_invalid, amount_mismatch, unmapped_account, unresolved_symbol, unknown_cost, insufficient_units, duplicate_line.
  - Decimals go through the bounded wire classes. Plain digits beyond scale 12, or qty × price beyond scale 12 (T012 note), give `scale_overflow`; nothing is rounded. Timestamps go through `parse_instant` (offset required).
  - Accounts resolve through `SourceMap` for the request tenant; unknown, foreign-tenant and unmapped sources look the same. Symbols resolve through `SecurityMaster` (found only; ambiguous or unknown is quarantined).
  - Text cells starting with `= + - @ TAB CR` are quarantined; mapped numeric fields are validated by the decimal grammar instead. Messages never echo a cell. `spreadsheet_safe` is the export-side neutralizer.
  - Rows are evaluated in (effective time, account, source, record) order on `Journal.copy()`, so the preview never mutates the journal and row order does not matter. A sale with no prior cost is `unknown_cost`, checked before units.
  - `commit` is all or nothing: refused unless the preview is `validated`; a changed account revision is a `conflict`; events are trial-posted on a copy before the real journal. Re-import commits 0 events. The preview has an id, the SHA-256 file hash, the mapping version, per-row source refs, and `to_wire()` for `import_preview.schema.json` (row reasons appear as blocking issues).
