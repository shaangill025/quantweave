# ADR-007: Tenant-private default and migration

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q31,Q39,Q51,Q52,Q75.

## Context
Open-source software is not public user data.

## Decision
Separate financial/research/private-learning scope with consent and rights before sharing.

## Consequences and acceptance
Export omits secrets/executables; deletion carries through backups and derivative availability.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
