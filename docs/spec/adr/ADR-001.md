# ADR-001: Independent modular core

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q6,Q13,Q22,Q36,Q70.

## Context
Avoid service proliferation; keep experimental execution and release authority out of live process.

## Decision
Use Python domain modules shared by hosted API, self-hosted processes, simulations and workers. TypeScript/React is a client.

## Consequences and acceptance
Cross-module ownership and shared conformance tests become mandatory.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
