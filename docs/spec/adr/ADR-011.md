# ADR-011: Open source commercial packaging

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q1,Q7,Q21,Q22,Q55,Q79.

## Context
No hosted dependency for core; licensing does not grant data or financial-advice permissions.

## Decision
Apache-2.0 complete core, paid managed service and BYO permitted providers.

## Consequences and acceptance
Commercial/legal/provider gates must be evidenced separately.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
