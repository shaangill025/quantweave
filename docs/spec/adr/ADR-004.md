# ADR-004: Explicit feed and capability registry

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q3,Q11,Q14,Q18,Q66,Q73.

## Context
Normalized API fields do not imply comparable market coverage or display/AI rights.

## Decision
Select feeds explicitly and qualify per strategy and deployment; fail affected capabilities closed.

## Consequences and acceptance
Provider updates may require reinitialization and requalification.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
