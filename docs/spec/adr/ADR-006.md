# ADR-006: Full self-improvement with protected release

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q28,Q30,Q33,Q37,Q38,Q39,Q76.

## Context
Breadth is mandatory; authority remains constrained.

## Decision
All six targets operational at first release; optimizer cannot edit protected assessment or self-promote.

## Consequences and acceptance
Real version lineage and next-cycle V1 execution required, not a written simulation.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
