# ADR-009: Financial-risk computation

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q44,Q49,Q68,Q69.

## Context
Concentration/cash/planned loss differ from worst possible loss.

## Decision
Long-only stock mode, allowed options catalogue, explicit numeric denominators and scoped loss pauses.

## Consequences and acceptance
Selling collateral may increase risk; check combined before/after exposure.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
