# ADR-010: Budgets and durable work

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q27,Q32,Q35,Q54,Q67,Q77.

## Context
Repeated model failures can otherwise exceed spend and invalidate timeliness.

## Decision
PostgreSQL-backed leases/outbox, bounded retries and atomic max-cost reservations.

## Consequences and acceptance
At-least-once consumers deduplicate; trigger times never reset.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
