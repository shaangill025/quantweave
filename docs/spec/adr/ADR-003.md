# ADR-003: Journal and source identity

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q4,Q12,Q42,Q43,Q58,Q71.

## Context
Ticker/source-file identities cannot substitute for underlying account identity.

## Decision
Use append/reversal decimal journal, distinct source observations and rebuildable snapshots.

## Consequences and acceptance
Idempotency, fee conventions, account reconciliation and temporal provenance must be tested.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
