# ADR-002: No broker execution

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q5,Q48,Q73,Q75.

## Context
Prompts alone cannot enforce this boundary.

## Decision
Provide only read-only connector operations; external execution reports and simulation orders are separate.

## Consequences and acceptance
Typed connector allowlists and test stubs must reject submit/amend/cancel/exercise.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
