# ADR-012: Specification contracts before implementation

Status: adopted design baseline, implementation not verified. Date: 2026-10-08. Decision lineage: Q70,Q78,Q79.

## Context
A generated contract or passing artifact linter is not an implemented application.

## Decision
This bundle defines designed interfaces and test expectations; real runtimes/check commands bind at T001/T008.

## Consequences and acceptance
Preserve explicit unimplemented/unverified states in receipts and release dashboard.

## Revisit trigger
New measured evidence, provider/legal conditions or explicit requirement changes justify a superseding ADR. Record impact and preserve earlier lineage; never silently weaken required first-release scope.
